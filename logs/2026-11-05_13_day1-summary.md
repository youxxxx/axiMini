## Found while writing it: an undeclared direct dependency
`scripts/download_ember.py` does `from huggingface_hub import hf_hub_download`, but `huggingface_hub` wasn't in `requirements.txt`. It only worked because thrember depends on it (`pip show thrember` → `Requires: huggingface_hub, ...`). If a future thrember version dropped that dependency, a fresh install would break at step 1. **Rule:** declare what you import, not just what happens to be installed transitively. Added `huggingface_hub>=0.24`; the installed 2.4.0 satisfies it, so no reinstall is needed.
